# Profe Rubencho Tools

Aplicación web estática para crear evaluaciones, diapositivas, planeaciones y diarios de campo en español.

## Publicación

La versión publicada está disponible en GitHub Pages:

https://seducativosintegrales.github.io/profe-rubencho-tools/

La app funciona en el navegador, guarda el trabajo localmente y usa CDN para las exportaciones PDF y PPTX. Los referentes DBA, estándares y procesos son sugerencias editables; verifica siempre la versión vigente. El formato de evaluación está inspirado en procesos tipo Saber y no tiene aval oficial del MEN o del ICFES.
